Like for like: PM2.5

Fine particles (PM2.5) are what haze is mostly made of, and both agencies publish the raw concentration in the same unit. This is the one figure you can compare directly.

PSI and API are not the same scale. Singapore's Pollutant Standards Index and Malaysia's Air Pollutant Index both run 0–500 with similar band names, but they are computed differently (different averaging rules and breakpoints), so a PSI of 150 and an API of 150 don't describe the same air. Compare the µg/m³ figures above instead.
